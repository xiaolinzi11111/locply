# Security

If you believe you have found a security issue in Locply:

1. Prefer private disclosure (email or contact form on https://www.locply.com/).
2. Do **not** open a public GitHub/Gitee issue with exploit details.
3. Include OS / browser version, Locply version, and a minimal reproduction if possible.

We will acknowledge reports and work on fixes as appropriate for a closed-source product.
