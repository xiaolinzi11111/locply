# Security

If you believe you have found a security issue in Locply:

1. Prefer private disclosure: email the contact on [https://www.locply.com/legal/privacy/](https://www.locply.com/legal/privacy/) (do not attach datasets unless necessary).
2. Do **not** open a public GitHub issue with exploit details.
3. Include OS / browser or desktop version, and a minimal reproduction if possible.

Imported user tables are processed on the device. Reports about “data uploaded to Locply” should distinguish **dataset contents** from ordinary HTTPS (Cloudflare logs, license policy, desktop launch ping, updates).

We will acknowledge reports and work on fixes as appropriate for a closed-source product.
