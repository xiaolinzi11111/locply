# Contributing

Locply application **source code is not open**. This public repository is for:

- Product documentation (web SQLite + desktop DuckDB, download links)
- Bug reports and feature requests

## How to help

1. Open an [Issue](../../issues) with a clear title and steps to reproduce (for bugs).
2. Search existing issues before filing a duplicate.
3. Do not submit pull requests that add application source — they will be closed.

## Security

See [SECURITY.md](SECURITY.md). Do not file public issues for sensitive vulnerabilities.
